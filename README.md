O Mãos Locais é um projeto interativo que simula o funcionamento completo de uma loja virtual voltada para o comércio de artesanato brasileiro. Desenvolvido sobre o ecossistema do Node.js com a velocidade do Vite, o projeto utiliza TypeScript para garantir uma tipagem estrita de dados e consistência nas regras de negócio da simulação, como cálculo de frete, carrinho de compras e checkout. A interface traduz a rica cultura do artesanato em um fluxo de navegação fluido, dinâmico e amigável.

Projetado para demonstrar boas práticas no desenvolvimento web moderno, este projeto simula a experiência de navegação e compra de produtos artesanais. Construído utilizando Node.js e empacotado com o Vite, a aplicação se destaca pelo carregamento ultrarrápido, estrutura modular e gerenciamento eficiente de estados no cliente. A combinação com JavaScript moderno e TypeScript permite simular interações complexas — como buscas em tempo real, pedidos personalizados e filtros avançados — com altíssimo desempenho.

Este projeto consiste em uma simulação funcional de um e-commerce artesanal focado na experiência do usuário e na valorização de mestres artesãos. A aplicação utiliza o TypeScript para modelar com precisão as entidades do sistema (produtos, categorias, artesãos, avaliações e pedidos), reduzindo falhas em tempo de execução e aumentando a confiabilidade do código. A integração com o ambiente Node.js e a estrutura do Vite possibilita uma arquitetura leve, escalável e de fácil manutenção.

O projeto Mãos Locais simula a jornada de compra em uma loja de produtos feitos à mão, reunindo catálogo filtrável, perfis de criadores, simulação de pagamento via Pix/Cartão e acompanhamento de entrega. Alimentado por JavaScript e TypeScript, o projeto gerencia todo o estado da simulação diretamente no navegador, incluindo a persistência de favoritos e itens do carrinho. O suporte da ferramenta Vite e a infraestrutura do Node.js garantem uma aplicação altamente responsiva e fluida.

O Mãos Locais é um projeto web que simula uma plataforma de e-commerce dedicada ao artesanato regional. Desenvolvido com JavaScript, TypeScript, Node.js e Vite, o projeto combina uma interface visual aconchegante em HTML e CSS a uma lógica de front-end robusta e tipada. A aplicação demonstra o fluxo completo de navegação, carrinho de compras, cálculo de frete e envio de encomendas sob medida de forma totalmente interativa.
